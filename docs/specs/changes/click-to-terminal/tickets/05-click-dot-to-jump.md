# 05-點圓點或清單列直接跳轉

**做完能 demo 什麼**：紅綠燈版左鍵點一下某個 session 的圓點（開啟「顯示專案名稱」時點整列也可以），就切到它的分頁；按住拖動超過門檻仍然是移動桌寵、不會跳轉；沒有 session 時點那顆灰點沒有任何反應。

**Blocked by**：03-右鍵「切換到終端機」

**狀態**：待做

**檢查點**：否

## 規格依據

- US-JUMP-01
- AC-JUMP-01、AC-JUMP-02、AC-JUMP-07、AC-JUMP-08（點擊部分）、AC-JUMP-12
- 修改後的 AC-OPS-04（點一下不移動桌寵，點在圓點／清單列上才跳轉）

## 驗收條件

- [ ] AC-JUMP-01（成功）：Given 同 03 卡的三分頁情境，外觀為紅綠燈版 → When 左鍵點一下 `abc123` 的圓點 → Then 切到第 2 個分頁；桌寵位置不變、不出現提示
- [ ] AC-JUMP-02（成功）：Given 同上，已開啟「顯示專案名稱」 → When 點 `abc123` 那一列（圓點或文字） → Then 切到第 2 個分頁
- [ ] AC-JUMP-07（邊界）：Given 左鍵按在某個圓點上 → When 拖動 30 px 後放開 → Then 桌寵移到新位置並記住位置，不切換分頁
- [ ] AC-JUMP-08（邊界，點擊部分）：Given 非 Windows 系統 → When 點一下圓點 → Then 沒有任何反應、不出現提示
- [ ] AC-JUMP-12（邊界）：Given 紅綠燈版、沒有 session、只顯示 1 顆灰點 → When 點一下灰點 → Then 沒有任何反應
- [ ] AC-OPS-04（修改）：Given 桌寵在螢幕上 → When 點一下（移動未超過門檻）就放開 → Then 不更新記住的位置、桌寵不移動；點在圓點或清單列以外的位置沒有任何反應
- [ ] 技術：拖曳門檻用 `QApplication.startDragDistance()`
- [ ] 技術：既有測試與 lint 全綠
