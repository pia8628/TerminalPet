TerminalPet 使用說明
====================

這是一個會顯示在螢幕右下角的小狼桌寵，會依照 Claude Code 目前的
狀態切換表情（思考中／執行中／需要你介入／完成／閒置）。

安裝步驟
--------
1. 雙擊「Setup-TerminalPet.exe」。

2. 如果跳出藍色視窗寫著「Windows 已保護您的電腦」：
   這是因為這個程式沒有花錢申請微軟的數位簽章，不代表有問題。
   請點視窗裡的「其他資訊」，再點「仍要執行」即可繼續安裝。

3. 依畫面指示選擇外觀（動物版 / 紅綠燈版），並選擇是否要
   「開機自動啟動」（建議選是，這樣以後不用每次手動開啟）。

4. 安裝完成後，桌寵會立刻出現在螢幕右下角。之後只要正常使用
   Claude Code，桌寵就會自動跟著切換狀態，不需要再做任何事。

操作方式
--------
- 拖曳：滑鼠左鍵按住拖動
- 關閉：在桌寵上按滑鼠右鍵 →「關閉桌寵」

如果想暫時關閉、下次開機還要自動啟動，直接關閉即可，不需要
解除安裝。

解除安裝
--------
重新執行一次「Setup-TerminalPet.exe」，選單會偵測到已安裝，
選擇「解除安裝」即可，會自動清除桌寵相關設定，不會動到你
Claude Code 原本的其他設定。

常見問題
--------
Q: 桌寵一直沒反應，沒有跟著狀態變化？
A: 確認一開始桌寵有成功跳出來（如果沒有，重新執行一次
   Setup-TerminalPet.exe 安裝）。如果桌寵有出現但一直不變化，
   代表 hook 沒有正確寫入，請解除安裝後重新安裝一次。

Q: 電腦上已經有裝 Python 了，會不會衝突？
A: 不會。這個工具是完全獨立打包的執行檔，不會使用、也不會
   影響你電腦上任何既有的 Python 安裝。
